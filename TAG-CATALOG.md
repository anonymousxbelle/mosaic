# Mosaic taxonomy

Updated September 13, 2026.

Content class (fiction/nonfiction) → genre → subgenre. Themes, tropes, settings, tone, audience and format are overlapping facets. Unknown content class is retained rather than guessed. Parent links guide suggestions, not universal exclusions.

Anime is a subgenre of the animation format; it remains a distinct tag. Biography and memoir are nonfiction genres. Adult audience does not mean adult content. New labels require explicit catalog evidence or user tagging; the existing synopsis rules recognize only a subset.

## class

| Tag | Content class | Parents / applicability | Description |
|---|---|---|---|
| fiction | Either / unclassified | Shared | Invented stories, even when inspired by real events. |
| non-fiction | Either / unclassified | Shared | Works presented as factual, rather than invented stories. |
