# Evidence and limitations

[Back to README](../README.md) · [How Mosaic works](IMPLEMENTATION.md)

The latest completed checks before this README revision passed **160 automated tests**, type-checking and the Pages build. These checks cover implementation behavior; they do not demonstrate participant satisfaction or recommendation superiority.

We saved a reference version on November 12, 2026 so study feedback could be tied to the software participants used. Later fixes changed that experience. When reporting results, identify which version each group tested and explain relevant changes; feedback from before a fix should not be presented as feedback on the fixed version. See the [baseline](STUDY-FREEZE-v1.md) and [change log](PARTICIPANT-FEEDBACK-LOG.md).

Known limitations include incomplete or inaccurate metadata, mixed-language/edition records, imperfect series grouping, bounded retrieval, provider failures and browser-local persistence. A strong candidate can be missed before ranking if it is not retrieved. Participant results and any comparison claims must be supported by actual collected evidence.
